# Участие в разработке My Cycle

[![en](https://img.shields.io/badge/lang-en-red.svg)](CONTRIBUTING.md)
[![ru](https://img.shields.io/badge/lang-ru-blue.svg)](CONTRIBUTING.ru.md)

Pull Request'ы и сообщения об ошибках приветствуются. Пожалуйста, делайте изменения целевыми и сохраняйте privacy-first и офлайн-концепцию проекта.

## 🐛 Сообщения об ошибках

Перед созданием нового Issue проверьте, не сообщал ли кто-то об этой проблеме ранее.

Укажите:

- понятное описание проблемы
- шаги для воспроизведения
- ожидаемое и фактическое поведение
- версию Android и модель устройства, если это важно
- скриншоты, если они помогают объяснить проблему

Не публикуйте в открытых Issue реальные данные цикла, личные заметки, экспортированные CSV-файлы и другую конфиденциальную информацию.

## 💡 Предложения функций

Создайте Issue и опишите:

- какую проблему решает функция
- как она должна работать
- влияет ли она на конфиденциальность, хранение данных, разрешения или сетевой доступ

Функции, добавляющие аккаунты, облачную синхронизацию, аналитику, рекламу или фоновый сетевой доступ, требуют отдельной тщательной проверки с точки зрения конфиденциальности.

## 🧑‍💻 Изменения кода

1. Сделайте fork репозитория.
2. Создайте отдельную целевую ветку.
3. Внесите минимально необходимое изменение.
4. Добавьте или обновите тесты, если меняется поведение.
5. Запустите проверки проекта.
6. Создайте Pull Request с кратким объяснением изменения.

## ✅ Проверка проекта

Требования:

- JDK 21
- Android SDK 36
- Gradle 8.13

В репозитории сейчас нет `gradle-wrapper.jar`, поэтому используйте установленный Gradle 8.13.

```bash
gradle assembleDebug assembleRelease test
gradle lint
```

## 🧭 Стиль кода

- Следуйте Kotlin coding conventions.
- Храните пользовательские строки в Android string resources.
- По возможности не размещайте доменную логику в Composable-функциях.
- Предпочитайте небольшие, целевые функции и классы.
- Сохраняйте lifecycle-aware сбор Flow и существующие подходы к управлению состоянием.
- Не добавляйте сетевые разрешения, аналитику или рекламные зависимости без отдельного решения по проекту.

## 🌍 Переводы

Английский — язык приложения по умолчанию. Русская локализация поддерживается параллельно.

При изменении пользовательского текста:

- обновляйте английские и русские ресурсы
- сохраняйте формулировки достаточно короткими для мобильного интерфейса
- не ломайте placeholders и plurals
- проверяйте эквивалентность смысла в обоих языках
