# My Cycle Privacy Policy

Effective date: September 13, 2026.

My Cycle is a local period diary for Android. It is designed so that cycle records do not need to be transmitted to the developer or to third parties.

## Data used by the app

Users may choose to store dates, bleeding information, mood, symptoms, and notes. This information remains on the user's device in a local database and is used only for the diary, calendar, statistics, approximate calendar estimates, and local patterns derived from the user's own records.

App settings are also stored locally on the device.

## Data collection and sharing

My Cycle does not create user accounts, send cycle records to the developer, use analytics, advertising SDKs, or tracking services, or share user data with third parties.

The app does not request the Android `INTERNET` permission.

## User-initiated exports and backups

Users can explicitly create:

- a CSV file containing diary records;
- a PDF summary intended for sharing with a doctor;
- a `.mycycle` data backup.

Each file is created only after an explicit user action and is saved through the Android system interface to a location selected by the user. The app does not upload these files to a developer-operated server.

The PDF summary intentionally omits free-text user notes. CSV and `.mycycle` backups may contain diary data according to the purpose of the export selected by the user.

After a file is saved, protection of the resulting file depends on the chosen storage location and any apps to which the user grants access.

## Android system backup

Automatic Android backup for My Cycle data is disabled. App data is not intended to be automatically transferred through cloud backup or device-to-device restore.

## Deleting data

All records and settings can be deleted from within the app. Uninstalling the app also removes its local app data according to Android behavior.

## Children

My Cycle does not require registration and does not collect server-side user data. The app is not designed to obtain children's personal data for the developer.

## Policy changes

If My Cycle changes how it handles data, this policy will be updated before the corresponding app version or store-listing update is published.
