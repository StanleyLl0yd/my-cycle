# My Cycle

[English](README.md) | [Русский](README_RU.md)

Приватный офлайн-трекер менструального цикла для Android.

**Текущая версия:** 1.0.0  
**Android:** 8.0 (API 26) и новее  
**Application ID:** `com.silverlightning.mycycle`

## Возможности

### Первоначальная настройка

При первом запуске приложение запрашивает:

- первый день последних месячных;
- обычную длину цикла — от 21 до 45 дней.

Начальная расчётная длительность менструации составляет 5 дней. В дальнейшем она корректируется по истории завершённых циклов.

### Сегодня

Экран «Сегодня», когда данных достаточно для расчёта, показывает:

- текущий день цикла;
- рассчитанную фазу цикла;
- примерное время до следующих месячных;
- идёт ли сейчас расчётное фертильное окно либо сколько дней осталось до его начала.

Текущий день можно сразу открыть для внесения записи.

### Ежедневные записи

Для сегодняшней и прошедших дат можно сохранять:

- интенсивность выделений: мажущие, слабые, средние, обильные или отсутствие месячных;
- настроение: отлично, хорошо, нормально или не очень;
- симптомы;
- произвольную заметку.

Будущие даты можно просматривать в календаре, но сохранять для них фактические записи нельзя.

### Календарь

Календарь позволяет переходить между месяцами и показывает:

- подтверждённые дни месячных с учётом интенсивности;
- расчётные дни следующих месячных;
- расчётное фертильное окно;
- расчётный день овуляции.

Нажатие на дату открывает ежедневную запись.

### Статистика

После появления завершённых циклов экран «Статистика» показывает:

- среднюю длину цикла;
- среднюю длительность месячных;
- регулярность цикла, если есть не менее двух завершённых циклов;
- до 12 последних распознанных циклов, включая текущий цикл, когда это применимо.

### Настройки

Доступны:

- системная, светлая и тёмная темы;
- динамические цвета Material You на Android 12+;
- экспорт данных в CSV через системный диалог Android;
- полное удаление данных цикла и настроек приложения;
- раздел «О приложении» с описанием, автором, версией, лицензией, информацией о конфиденциальности и ссылками на лицензию и GitHub.

Интерфейс доступен на английском и русском языках.

## Как работают расчёты

При первом использовании расчёты основаны на выбранной длине цикла, дате начала последних месячных и начальной длительности менструации 5 дней.

После появления завершённых циклов приложение использует до 6 последних завершённых циклов. Более новые циклы имеют больший вес при расчёте средней длины цикла и длительности месячных.

Расчётная дата овуляции определяется как 14 дней до предполагаемого начала следующих месячных. Расчётное фертильное окно начинается за 5 дней до овуляции и заканчивается через 1 день после неё.

Это календарные оценки, а не медицинские измерения.

## Чего нет в версии 1.0.0

Текущая версия **не поддерживает**:

- уведомления и напоминания;
- импорт данных;
- регистрацию аккаунта;
- облачную синхронизацию и облачное хранение;
- аналитику и рекламу.

## Конфиденциальность

Данные цикла хранятся локально в Room, настройки приложения — в DataStore.

Приложение:

- не запрашивает Android-разрешение `INTERNET`;
- не требует аккаунта;
- не содержит SDK аналитики или рекламы;
- отключает резервное копирование данных приложения средствами Android;
- исключает файлы, базы данных и настройки приложения из правил облачного резервного копирования и переноса данных между устройствами;
- передаёт данные за пределы приложения только когда пользователь сам создаёт CSV-файл экспорта.

Ссылки на GitHub и лицензию из раздела «О приложении» открываются системой во внешнем приложении, например браузере.

## Важное медицинское примечание

My Cycle — **не медицинское устройство**. Даты месячных, фазы цикла, фертильного окна и овуляции являются расчётными. Не используйте эти оценки как метод контрацепции или замену профессиональной медицинской консультации.

## Установка

Подписанный APK текущего публичного релиза доступен на странице [GitHub Releases](https://github.com/StanleyLl0yd/my-cycle/releases).

## Сборка из исходного кода

Требования:

- JDK 21;
- Android SDK 36;
- Gradle 8.13.

В репозитории сейчас нет `gradle-wrapper.jar`, поэтому для сборки из командной строки требуется установленный Gradle 8.13.

```bash
git clone https://github.com/StanleyLl0yd/my-cycle.git
cd my-cycle
gradle assembleDebug test
gradle lint
```

Для создания неподписанного release APK:

```bash
gradle assembleRelease
```

Конфигурация release-подписи в репозитории отсутствует. APK, прикреплённый к официальному GitHub Release, подписывается отдельно.
