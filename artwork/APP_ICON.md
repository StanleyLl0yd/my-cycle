# App icon provenance

The canonical owner-approved My Cycle app icon is the original raster PNG named `Нежный календарь с цветочным акцентом.png`.

- Canonical source dimensions: 1254×1254
- Canonical source SHA-256: `cc9fe5e688503682ce06f1b7e4e77a1a510635152185476b901b2af2a5f40cac`
- Android launcher derivative currently committed at `app/src/main/res/mipmap-mdpi/ic_launcher.png`
- Android derivative dimensions: 48×48
- Android derivative SHA-256: `9fced763f7937d732cf17edc277a023841e94d8971b1cd32b10e7571b8fbbc28`

The derivative was produced only by raster resizing from the canonical PNG. The artwork must not be traced, vectorized, redrawn, restyled or otherwise redesigned. CI verifies the committed derivative checksum and rejects the removed VectorDrawable/adaptive-icon replacement paths.

The canonical 1254×1254 source bytes are retained outside this repository until the repository connector can upload that binary losslessly; its SHA-256 above is the integrity reference. A future repository update should add that exact PNG byte-for-byte and derive density-specific raster assets from it without visual changes.
