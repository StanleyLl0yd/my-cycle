# Политика конфиденциальности «Мой Цикл»

Дата вступления в силу: 13 сентября 2026 года.

«Мой Цикл» — локальный дневник месячных для Android. Приложение спроектировано так, чтобы записи пользователя не требовали передачи данных разработчику или третьим лицам.

## Какие данные используются

Пользователь может самостоятельно сохранять в приложении даты, сведения о кровотечении, настроение, симптомы и заметки. Эти сведения хранятся только на устройстве пользователя в локальной базе данных и используются для работы дневника, календаря, статистики, примерных календарных расчётов и локальных закономерностей по собственным записям пользователя.

Настройки приложения также хранятся только на устройстве.

## Передача и сбор данных

«Мой Цикл» не создаёт аккаунт пользователя, не отправляет записи разработчику, не использует аналитику, рекламные SDK или средства отслеживания и не передаёт пользовательские данные третьим лицам.

Приложение не запрашивает Android-разрешение `INTERNET`.

## Экспорт и резервные копии по инициативе пользователя

Пользователь может самостоятельно создать:

- CSV-файл с записями дневника;
- PDF-сводку для врача;
- резервную копию данных в формате `.mycycle`.

Каждый такой файл создаётся только после явного действия пользователя и сохраняется через системный интерфейс Android в место, выбранное пользователем. Приложение не отправляет созданные файлы на сервер разработчика.

PDF-сводка намеренно не включает свободные текстовые заметки пользователя. CSV и резервная копия `.mycycle` могут содержать данные дневника в соответствии с назначением выбранного пользователем экспорта.

После сохранения дальнейшая защита созданного файла зависит от выбранного пользователем места хранения и приложений, которым пользователь самостоятельно предоставляет к нему доступ.

## Системное резервное копирование Android

Автоматическое резервное копирование данных «Мой Цикл» средствами Android отключено. Данные приложения не предназначены для автоматической передачи через облачное резервное копирование или перенос между устройствами.

## Удаление данных

Все записи и настройки можно удалить средствами самого приложения. Удаление приложения также удаляет его локальные данные в соответствии с поведением Android.

## Дети

«Мой Цикл» не требует регистрации и не собирает данные на сервере. Приложение не предназначено для получения персональных данных детей разработчиком.

## Изменения политики

Если способ обработки данных в «Мой Цикл» изменится, эта политика будет обновлена до выпуска соответствующей версии приложения или публикации соответствующего обновления карточки приложения.
