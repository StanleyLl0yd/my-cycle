## Полное описание

«Мой Цикл» — приватный дневник месячных для Android, который помогает вести календарь без аккаунта, рекламы и передачи записей в интернет.

В приложении можно:

- отмечать дни месячных, интенсивность кровотечения и отдельные дни с небольшими выделениями;
- добавлять настроение, симптомы и заметки;
- быстро вносить прошлые месячные по датам начала и окончания;
- смотреть календарь с реальными записями и примерным диапазоном следующих месячных;
- видеть статистику по недавней истории циклов;
- экспортировать свои записи в CSV;
- выбрать светлую, тёмную или системную тему.

«Мой Цикл» учитывает, что цикл может быть разным: в первые годы после начала месячных, при нестабильном цикле и возрастных изменениях прогнозы становятся шире и осторожнее. Если данных недостаточно, приложение не пытается изображать точность, которой нет.

Все записи о цикле хранятся только на устройстве. Приложение не требует регистрации, не содержит рекламы и аналитики и не запрашивает разрешение `INTERNET`. Резервное копирование данных приложения средствами Android отключено.

Важно: «Мой Цикл» — дневник и календарный помощник, а не медицинское изделие и не средство контрацепции. Примерные даты не подтверждают овуляцию, беременность или диагноз и не заменяют консультацию врача.

## Что нового

Первая публикация «Мой Цикл» в RuStore.

- Быстрый ввод прошлых месячных по датам начала и окончания.
- Более простой ежедневный ввод: кровь — сразу, настроение, симптомы и заметки — по желанию.
- Улучшены календарь, доступность и работа на небольших экранах.
- Повышена надёжность сохранения данных.

Записи остаются только на устройстве: без аккаунта, рекламы, аналитики и доступа в интернет.

## Комментарий для модератора

Авторизация не требуется. Приложение «Мой Цикл» работает офлайн и не запрашивает разрешения.

Для проверки можно пройти первоначальную настройку, после чего доступны экраны «Сегодня», «Календарь», «Статистика» и «Настройки». Прошлые циклы можно добавить вручную через календарь.

Пользовательские данные хранятся только локально на устройстве. В приложении отсутствуют реклама, аналитика, сторонние трекеры и сетевое взаимодействие.

## Безопасность данных

Приложение не передаёт пользовательские данные разработчику или третьим лицам.

Даты цикла, интенсивность кровотечения, настроение, симптомы и заметки сохраняются только локально на устройстве.

Сетевых SDK, рекламы и аналитики нет. Разрешение `INTERNET` отсутствует.

CSV создаётся только по явному действию пользователя и сохраняется через системный интерфейс Android в выбранное пользователем место.

Резервное копирование данных приложения средствами Android отключено.

## Материалы публикации

- Скриншоты телефона генерируются вручную workflow `RuStore Screenshots` и скачиваются из его artifact.
- Иконка для карточки RuStore хранится вне репозитория и загружается в консоль публикации вручную.
- Основной файл публикации `My-Cycle-v1.1.3.aab` и сертификат ключа загрузки берутся из GitHub Release версии 1.1.3.

Перед первой загрузкой AAB в RuStore Консоль нужно один раз загрузить подпись приложения через PEPK и сертификат ключа загрузки. Уникальный `encryptionkey` для PEPK выдаёт RuStore Консоль.
