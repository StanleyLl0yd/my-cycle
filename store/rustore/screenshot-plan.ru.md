# RuStore — план скриншотов «Мой Цикл» 1.4.0

Цель: 4–5 вертикальных скриншотов 9:16, каждый показывает реальный интерфейс и отдельную сильную сторону приложения. Текст — только на русском. Не использовать кликбейт и не изображать функциональность, которой нет в релизе.

## 01 — Сегодня / объяснимый прогноз

Экран: «Сегодня» с заполненной историей и видимым диапазоном следующих месячных.

Текст поверх скриншота:

**Примерный прогноз без ложной точности**

Подзаголовок:

Диапазон дат и понятное объяснение, на каких циклах он основан

## 02 — Календарь

Экран: «Календарь» с реальными отмеченными днями и прогнозным диапазоном.

Текст поверх скриншота:

**Весь цикл в календаре**

Подзаголовок:

Месячные, выделения и примерные будущие даты — в одном месте

## 03 — Закономерности / статистика

Экран: «Статистика» с видимыми средними значениями, самым коротким/длинным циклом и карточками повторяющихся симптомов.

Текст поверх скриншота:

**Замечайте закономерности**

Подзаголовок:

Статистика и повторяющиеся симптомы только по вашим записям

## 04 — Дневник симптомов

Экран: редактирование дня с интенсивностью, настроением и симптомами.

Текст поверх скриншота:

**Записывайте только то, что важно вам**

Подзаголовок:

Кровотечение, настроение, симптомы и заметки без обязательных анкет

## 05 — Приватность / отчёт для врача

Экран: «Настройки» с блоком экспорта и «Отчёт для врача».

Текст поверх скриншота:

**Ваши данные остаются у вас**

Подзаголовок:

Без аккаунта, рекламы и аналитики. PDF-отчёт создаётся локально

## Требования к итоговым файлам

- вертикальная ориентация 9:16;
- PNG или JPG;
- не менее 320 px по стороне;
- не более 2160×3840 px для мобильной версии;
- не более 3 МБ на файл — целевой предел для безопасной загрузки через веб-консоль;
- одинаковая ориентация всех кадров;
- не показывать системную панель Android или интерфейс других приложений;
- проверить, что подписи не перекрывают существенные элементы UI;
- порядок публикации: 01 → 02 → 03 → 04 → 05.
