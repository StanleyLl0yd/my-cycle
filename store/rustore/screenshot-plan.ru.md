# RuStore — план скриншотов «Мой Цикл» 1.4.0

Цель: пять вертикальных скриншотов 9:16, каждый показывает реальный интерфейс и отдельную сильную сторону приложения. Текст — только на русском. Не использовать кликбейт и не изображать функциональность, которой нет в релизе.

## 01 — Сегодня / объяснимый прогноз

Экран: «Сегодня» с заполненной историей и видимым диапазоном следующих месячных.

**Прогноз без ложной точности**

Диапазон дат и объяснение — на основе вашей истории.

## 02 — Календарь

Экран: «Календарь» с реальными отмеченными днями и прогнозным диапазоном.

**Весь цикл в календаре**

Записи и примерные будущие даты — в одном месте.

## 03 — Статистика цикла

Экран: верхняя часть «Статистики» со средними значениями, самым коротким/длинным недавним циклом и вариативностью.

**Цикл в цифрах**

Средние значения и недавний диапазон — по вашим записям.

## 04 — Закономерности симптомов

Экран: прокрученная «Статистика» с карточками повторяющихся симптомов.

**Замечайте закономерности**

Повторяющиеся симптомы только по вашей недавней истории.

## 05 — Приватность / отчёт для врача

Экран: «Настройки» с локальной защитой, экспортом и «Отчётом для врача».

**Ваши данные остаются у вас**

Без аккаунта, рекламы и аналитики. PDF создаётся локально.

## Требования к итоговым файлам

- вертикальная ориентация 9:16;
- PNG или JPG;
- целевой размер 1080×1920;
- не более 3 МБ на файл;
- одинаковая ориентация всех кадров;
- только фактический UI версии 1.4.0;
- не показывать System UI Android или интерфейс других приложений;
- порядок публикации: 01 → 02 → 03 → 04 → 05.
