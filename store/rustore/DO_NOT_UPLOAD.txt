Не загружать в RuStore как публикационные материалы:
- debug APK;
- APK/AAB из pull request artifacts;
- старые бинарники 1.1.x/1.3.x;
- скриншоты старого интерфейса без Insights 1.4.0;
- изображения с системным Android UI;
- материалы, обещающие точную овуляцию, диагноз, контрацепцию или «безопасные дни».

Использовать только immutable GitHub Release v1.4.0 и актуальные store assets.
