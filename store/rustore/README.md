# RuStore publishing kit — My Cycle 1.4.0

Этот каталог содержит подготовленные материалы для публикации «Мой Цикл» 1.4.0 в RuStore.

## Тексты

- `listing.ru.md` — полная карточка приложения, ASO-описания, disclaimer и данные для модерации.
- `whats-new.ru.txt` — текст поля «Что нового».
- `moderator-note.ru.txt` — комментарий для модератора.
- `data-safety.ru.md` — ответы и формулировки по безопасности данных.
- `aso-keywords.ru.txt` — семантическое ядро и запрещённые/нежелательные обещания.
- `publication-checklist.ru.md` — финальный чек-лист консоли RuStore.
- `screenshot-plan.ru.md` — порядок, подписи и требования к скриншотам.

Политика конфиденциальности и пользовательское соглашение находятся в корне репозитория: `PRIVACY.ru.md` и `TERMS.ru.md`.

## Бинарные материалы

Бинарники не дублируются в git. Использовать immutable GitHub Release `v1.4.0`:

- `My-Cycle-v1.4.0.aab`
