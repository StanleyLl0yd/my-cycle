# RuStore requirements snapshot — September 2026

Checked against current RuStore developer documentation before preparing the 1.4.0 package.

## Listing text

- short description: up to 80 characters;
- full description: up to 4000 characters;
- avoid clickbait, misleading claims, keyword stuffing and unsupported “official/best/unique” language;
- for My Cycle, avoid claims of diagnosis, confirmed ovulation, contraception efficacy or “safe days”.

## Developer contact

At least one contact method is required in the RuStore Console for new app versions.

## Icon

Target package asset:

- 512×512 px;
- PNG or JPG;
- square;
- full background fill, no transparent/unfilled outer contour;
- should visually match the installed application icon.

## Phone screenshots

- mandatory for the mobile app listing;
- at least 3 screenshots;
- up to 10 can be uploaded together;
- PNG or JPG;
- same orientation for the whole set;
- use 9:16 portrait for this package;
- maximum mobile resolution 2160×3840;
- keep files below 3 MB for conservative compatibility with the web-console publication guidance;
- screenshots must show the actual current UI and available functionality;
- screenshots must not show Android system UI or other apps;
- overlay text must be Russian or English and must not be misleading.

## Package recommendation

Use the signed release `My-Cycle-v1.4.0.aab` from the immutable GitHub Release v1.4.0.
