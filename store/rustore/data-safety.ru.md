# RuStore — безопасность данных для «Мой Цикл» 1.4.0

## Сбор и передача данных

- Приложение не создаёт аккаунт и не требует регистрации.
- Приложение не передаёт пользовательские данные разработчику или третьим лицам.
- Реклама, SDK аналитики и сторонние трекеры отсутствуют.
- Разрешение Android `INTERNET` отсутствует.

## Какие данные могут храниться локально

Только на устройстве пользователя могут храниться:

- даты цикла и кровотечения;
- интенсивность кровотечения;
- настроение;
- отмеченные симптомы;
- свободные пользовательские заметки;
- настройки приложения и локальных напоминаний.

## Экспорт по инициативе пользователя

Только по явному действию пользователя приложение может создать:

- CSV с записями дневника;
- PDF-сводку для врача;
- полную резервную копию `.mycycle`.

Файл сохраняется через системный интерфейс Android в выбранное пользователем место. Приложение не отправляет экспортированный файл на собственный сервер.

PDF-отчёт намеренно не включает свободные личные заметки.

## Резервное копирование Android

Системное резервное копирование данных приложения отключено.

## Медицинские данные

Записи пользователя могут относиться к менструальному циклу и самочувствию. Они используются только локально для отображения календаря, статистики, приблизительных диапазонов дат и повторяющихся закономерностей.

«Мой Цикл» не является медицинским изделием, не ставит диагнозы и не предназначен для контрацепции.
