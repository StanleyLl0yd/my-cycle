Приватный офлайн-трекер менструального цикла для Android на Kotlin, Jetpack Compose и Material 3.

[⬇️ Скачать последнюю версию APK](https://github.com/StanleyLl0yd/my-cycle/releases/latest)

Текущая версия: **1.0.0** · Min SDK: **26 (Android 8.0)** · Target SDK: **36**

## ✨ Возможности

- Первоначальная настройка по первому дню последних месячных и обычной длине цикла от 21 до 45 дней
- Экран «Сегодня» с днём цикла, рассчитанной фазой, прогнозом следующих месячных и статусом фертильного окна
- Ежедневные записи: интенсивность выделений, настроение, симптомы и заметки
- Календарь с подтверждёнными днями месячных, прогнозом следующих месячных, фертильным окном и днём овуляции
- Статистика: средняя длина цикла, средняя длительность месячных, регулярность и история последних циклов
- Экспорт данных в CSV через системный диалог Android
- Полное удаление данных цикла и настроек приложения
- Системная, светлая и тёмная темы, а также динамические цвета Material You на Android 12+
- Английская и русская локализация
- Раздел «О приложении» с описанием, автором, версией, лицензией, информацией о конфиденциальности и ссылкой на GitHub

Будущие даты можно просматривать в календаре, но сохранять для них фактические записи нельзя.

## 📅 Как работают расчёты

При первом использовании расчёты основаны на выбранной длине цикла, дате начала последних месячных и начальной длительности менструации **5 дней**.

После появления завершённых циклов My Cycle использует до **6 последних завершённых циклов**. Более новые циклы получают больший вес при расчёте средней длины цикла и длительности месячных.

Расчётная дата овуляции определяется как **14 дней до предполагаемого начала следующих месячных**. Расчётное фертильное окно начинается **за 5 дней до овуляции и заканчивается через 1 день после неё**.

Это календарные оценки, а не медицинские измерения.

## 🔒 Конфиденциальность

- **100% офлайн для данных цикла** — приложение не запрашивает Android-разрешение `INTERNET`
- **Без аккаунта, аналитики, трекинга и рекламы**
- Данные цикла хранятся локально в базе Room
- Настройки приложения хранятся локально в DataStore
- Резервное копирование данных приложения средствами Android отключено
- Файлы, базы данных и настройки исключены из облачного резервного копирования и переноса между устройствами
- Данные покидают приложение только когда пользователь сам создаёт CSV-файл экспорта

Ссылки на GitHub и лицензию из раздела «О приложении» открываются Android во внешнем приложении, например браузере.

О проблемах безопасности сообщайте согласно [SECURITY.ru.md](SECURITY.ru.md).

## ⚕️ Важное медицинское примечание

My Cycle — **не медицинское устройство**. Даты месячных, фазы цикла, фертильного окна и овуляции являются расчётными. Не используйте эти оценки как метод контрацепции или замену профессиональной медицинской консультации.

## 🛠️ Сборка из исходного кода

Требования:

- JDK 21
- Android SDK 36
- Gradle 8.13

В репозитории сейчас нет `gradle-wrapper.jar`, поэтому для сборки из командной строки требуется установленный Gradle 8.13.

```bash
git clone https://github.com/StanleyLl0yd/my-cycle.git
cd my-cycle
gradle assembleDebug test
gradle lint
```

Для создания неподписанного release APK:

```bash
gradle assembleRelease
```

Конфигурация release-подписи в репозитории отсутствует. APK, прикреплённый к официальному GitHub Release, подписывается отдельно.
