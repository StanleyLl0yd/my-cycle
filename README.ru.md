Простой и приватный дневник месячных для Android. Он хранит настоящие даты и осторожно подсказывает возможные будущие даты, не делая вид, что у всех организм работает как часы по 28 дней.

[⬇️ Скачать последний опубликованный APK](https://github.com/StanleyLl0yd/my-cycle/releases/latest)

Версия исходного кода: **1.1.2** · Последний опубликованный APK: **1.1.2** · Min SDK: **26 (Android 8.0)** · Target SDK: **37**

## ✨ Возможности

- При первом запуске нужно выбрать вариант, который больше похож на вашу ситуацию сейчас:
  - месячные начались меньше года назад
  - месячные начались 1–3 года назад
  - месячные идут больше 3 лет, и промежутки обычно похожи
  - месячные идут больше 3 лет, но промежутки всё ещё сильно меняются
  - с возрастом месячные стали приходить по-разному
  - с возрастом месячные прекратились на целый год либо врач уже объяснил, что они закончились
- Без выбора первого варианта приложение дальше не пойдёт; позже выбор можно изменить в Настройках без удаления старых записей
- Старые записи из 1.0.0 и 1.1.0 сохраняются. Старые записи «Несколько пятен» считаются именно пятнами, а не полноценными месячными
- Экран «Сегодня» показывает, сколько дней прошло с начала последних месячных, и **примерный промежуток дат**, когда могут начаться следующие
- Любой прошедший день календаря можно открыть и изменить; прошлые месячные можно быстро добавить по дате начала и окончания
- Несколько предыдущих циклов можно внести подряд через действие «Добавить ещё»
- В ежедневной записи кровь и кнопка сохранения показаны сразу, а настроение, симптомы и заметки находятся в необязательном разделе «Ещё данные»
- «Несколько пятен» сохраняются в дневнике, но **не начинают новый цикл**
- Если между двумя днями с кровью вы явно отметили «Крови нет» или «Несколько пятен», приложение не склеит эти дни в одни месячные. Если день вообще не был заполнен, приложение может считать его просто пропущенной записью
- Одна дата начала месячных, введённая при первом запуске, не превращается в выдуманные «месячные длились 1 день». Длительность остаётся неизвестной, пока не появятся настоящие записи
- Календарь показывает настоящие записи и бледным цветом — только примерные будущие даты
- После нескольких достаточно похожих взрослых циклов календарь может показать широкий промежуток дней, когда беременность может быть вероятнее
- Статистика использует недавнюю историю: до 6 законченных циклов для основных чисел и до 12 циклов в списке истории
- Понятные предупреждения для некоторых слишком больших перерывов, слишком долгого кровотечения и новой крови после перерыва примерно в год
- Исправленная тёмная тема, более читаемые цвета и голосовые описания календаря для TalkBack
- Экспорт записей в CSV через обычное системное окно Android
- Полное удаление записей о месячных и настроек приложения
- Системная, светлая и тёмная темы, а также цвета Material You на Android 12+
- Английский и русский языки
- Раздел «О приложении» с описанием, автором, версией, лицензией, информацией о личных данных и ссылкой на GitHub

Будущие даты можно просматривать в календаре, но сохранять их как реальные события нельзя.

## 📅 Как работают расчёты

My Cycle считает календарь **подсказкой**, а не измерением того, что происходит в организме.

При первом запуске приложение спрашивает, какая ситуация вам подходит, когда начались последние настоящие месячные и примерно сколько дней обычно проходит до следующих. Первый вопрос обязательно нужно выбрать вручную. Вариант про прекращение месячных на целый год предназначен для возрастных изменений или ситуации, которую уже объяснил врач. Если месячных нет год по другой неизвестной причине, это стоит обсудить с врачом.

При обновлении прежний дневник остаётся без изменений. Если приложение ещё не знает, какой вариант вам подходит, оно специально показывает широкий промежуток и не рассчитывает выход яйцеклетки или дни повышенной вероятности беременности, пока вы не выберете подходящий вариант в Настройках.

Первый расчёт показывается как **промежуток дат**, а не один якобы точный день. Этот промежуток специально делается шире в первые годы после начала месячных, если промежутки много лет сильно меняются, когда месячные меняются с возрастом, а также когда промежутки довольно ровные, но их обычная длина выходит за частый диапазон, который использует приложение.

Когда появляется настоящая история, приложение берёт до **6 последних законченных циклов**. Более новые даты влияют сильнее. Если промежутки сильно отличаются друг от друга, предполагаемый срок становится шире.

Приложение **не знает**, когда именно выходит яйцеклетка. Только после не менее чем **3 достаточно похожих законченных взрослых циклов** оно может показать широкий календарный промежуток, когда беременность может быть вероятнее. В первые годы, при многолетних сильно разных промежутках, при возрастных изменениях, после возрастного прекращения месячных на целый год, пока подходящий вариант не выбран и при ровном, но выходящем за частый диапазон взрослом цикле такой расчёт не показывается.

Примерный промежуток, когда беременность может быть вероятнее, начинается за пять дней до широкого возможного промежутка выхода яйцеклетки и заканчивается вместе с ним. Это всё равно только календарное предположение.

Никогда не считайте цвета или даты в календаре «безопасными днями» для защиты от беременности.

В приложении есть несколько простых правил, когда стоит обратить внимание:

- в первые годы текущий или последний промежуток около **3 месяцев или больше** стоит обсудить с врачом или другим медицинским работником, которому вы доверяете
- позже неизвестная причина отсутствия месячных около **3 месяцев или больше** тоже заслуживает разговора с врачом, если беременность не ожидается
- через 1–3 года после начала месячных промежутки короче примерно **21 дня** или длиннее примерно **45 дней** заслуживают внимания
- после первых 3 лет, если промежутки обычно похожи, значения короче примерно **21 дня** или длиннее примерно **35 дней** заслуживают внимания, особенно если это повторяется
- если кровь идёт дольше примерно **7 дней в первые годы** или дольше примерно **8 дней позже**, приложение может посоветовать обратиться за советом
- если месячные прекратились на целый год из-за возрастных изменений, новую кровь нужно обсудить с врачом, даже если её совсем немного

Эти подсказки не говорят, в чём причина, и не ставят диагноз.

## 🔒 Конфиденциальность

- **100% офлайн для записей о месячных** — приложение не запрашивает Android-разрешение `INTERNET`
- **Без аккаунта, аналитики, слежения и рекламы**
- Записи о месячных хранятся только на устройстве в локальной базе Room
- Настройки приложения хранятся только на устройстве в DataStore
- Резервное копирование данных приложения средствами Android отключено
- Файлы, базы данных и настройки исключены из облачного резервного копирования и переноса между устройствами
- Записи о месячных покидают приложение только тогда, когда вы сами создаёте копию CSV

Ссылки на GitHub и лицензию из раздела «О приложении» Android открывает во внешнем приложении, например в браузере.

О проблемах безопасности сообщайте согласно [SECURITY.ru.md](SECURITY.ru.md).

## ⚕️ Важное медицинское примечание

My Cycle — **дневник, а не врач и не медицинское обследование**. Приложение не может узнать, почему месячные пришли раньше или позже, почему крови стало больше или меньше и почему месячные пропали. Оно не может подтвердить, вышла ли яйцеклетка, возможна ли беременность в конкретный день и является ли какое-то изменение безобидным.

В первые годы после начала месячных большие скачки между датами часто бывают обычным делом. Они снова часто появляются, когда с возрастом месячные постепенно подходят к окончанию. Но это не значит, что любое необычное изменение можно игнорировать. Простые предупреждения в приложении основаны на широко используемых рекомендациях [ACOG](https://www.acog.org/clinical/clinical-guidance/committee-opinion/articles/2015/12/menstruation-in-girls-and-adolescents-using-the-menstrual-cycle-as-a-vital-sign) и [международных рекомендациях, обновлённых в 2023 году](https://www.asrm.org/practice-guidance/practice-committee-documents/recommendations-from-the-2023-international-evidence-based-guideline-for-the-assessment-and-management-of-polycystic-ovary-syndrome/).

Широкий примерный промежуток выхода яйцеклетки, который показывается только при достаточно ровной взрослой истории, учитывает, что между выходом яйцеклетки и следующими месячными не всегда проходит ровно 14 дней. Это также соответствует [рекомендациям ASRM](https://www.asrm.org/practice-guidance/practice-committee-documents/diagnosis-and-treatment-of-luteal-phase-deciency-a-committee-opinion-2021/), где этот промежуток может различаться на несколько дней.

Если крови очень много, вы чувствуете сильную слабость или близки к обмороку, боль очень сильная, возможна беременность или вам просто кажется, что что-то не так — не ждите подсказки приложения и обратитесь за медицинской помощью.

## 🛠️ Сборка из исходного кода

Требования:

- JDK 21
- Android SDK 37
- Gradle 9.5.0

В репозитории сейчас нет `gradle-wrapper.jar`, поэтому для сборки из командной строки требуется установленный Gradle 9.5.0.

```bash
git clone https://github.com/StanleyLl0yd/my-cycle.git
cd my-cycle
gradle --dependency-verification=strict assembleDebug assembleRelease test
gradle --dependency-verification=strict lint
gradle --dependency-verification=strict detekt
python3 scripts/check-source-comments.py
```

Без переменных для подписи `assembleRelease` создаёт неподписанный release APK.

Официальная подпись релизов настроена через GitHub Repository Secrets. Файл ключа и пароли не хранятся в репозитории. Обычный CI не получает Secrets для релизной подписи. Release workflow восстанавливает ключ только на время подписанной release-сборки, сразу удаляет его, проверяет сертификат автора подписи и публикует APK вместе с контрольной суммой SHA-256.

Сборка использует переменные `ANDROID_KEYSTORE_PATH`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS` и `ANDROID_KEY_PASSWORD`; GitHub Actions использует `ANDROID_KEYSTORE_BASE64`, чтобы временно восстановить файл ключа.

## ✅ Проверка проекта

Pull Request'ы и push в `main` автоматически проверяются:

- сборкой debug и release APK
- unit-тестами
- Android Lint
- Detekt
- Qodana
- CodeQL
- Semgrep
- Gitleaks с проверкой полной истории Git
- строгим Gradle dependency verification
- политикой комментариев в исходниках: минимум комментариев, только действительно необходимые и только на английском
- сохранением неподписанного release APK как artifact; обычный CI не получает Secrets для релизной подписи

Dependabot контролирует Gradle, GitHub Actions и закреплённый Python security tool. Сторонние GitHub Actions закреплены на неизменяемых commit SHA.

`Android Release` может автоматически запускаться из защищённой ветки `main` при изменениях, относящихся к релизу; ручной запуск остаётся резервным вариантом. Workflow ждёт успешный CI для точного commit, получает данные подписи только на время подписанной сборки, сразу удаляет файл ключа, проверяет сертификат и подписи APK v2/v3, не допускает повторной публикации той же версии и публикует официальный APK. Release-сборка использует R8 minification и shrink resources.
